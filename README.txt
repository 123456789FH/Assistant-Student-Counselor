مساعد الموجّه الطلابي — الإصدار ١٤
==================================

تطبيق عربي تفاعلي لتنظيم الخطة الأسبوعية واليومية، متابعة الإنجاز، توثيق الشواهد، وقياس الأثر، مع تصدير احترافي إلى Word وExcel وPDF.

الجديد في الإصدار ١٤:
- وحدة مستقلة «تقرير تنفيذ برنامج مدرسي».
- تصدير قالب Word DOCX قابل للتعبئة يدويًا.
- جداول Word أصلية، وليست HTML.
- Content Controls حقيقية وقوائم Word منسدلة.
- تقرير Word ثانٍ بالبيانات الحالية.
- أقسام: البيانات الأساسية، الأهداف، الفئة والمستفيدون، المكان والتاريخ، آلية التنفيذ، الأنشطة، النتائج، نقاط القوة، التوصيات، الشواهد، قياس الأثر، التوقيع والتاريخ.
- اعتماد البيانات المدخلة فقط دون اختراع نتائج أو نسب.
- دعم RTL وA4 وهوية لونية رسمية، مع خانة للشعار الرسمي الذي يرفعه المستخدم.
- الحفاظ على نموذج الشواهد الاحترافي ومزايا Word/Excel/PDF/JSON/PWA السابقة.

الخصوصية:
- بيانات النصوص تحفظ محليًا في المتصفح.
- صور الشواهد المؤقتة لا تدخل JSON أو التخزين المحلي.
