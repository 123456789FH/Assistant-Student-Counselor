مساعد الموجّه الطلابي — الإصدار ١٧

الإصدار ١٧ يضيف فوق الإصدار ١٦:
- تنبيهًا ذكيًا داخل التطبيق يحدد الأسبوع/المهمة التي تحتاج انتباهًا عند فتح التطبيق.
- لمبات حالة: أحمر للدور الحالي أو المتأخر، أصفر للتنفيذ الذي ينتظر اكتمال التقرير، أخضر للمكتمل والموثق، رمادي للقادم.
- تحديث الحالة تلقائيًا كل دقيقة أثناء فتح التطبيق.
- Dashboard تنفيذي في التقرير الختامي يعتمد على البيانات الفعلية فقط.
- إصلاح زر تثبيت PWA: تثبيت مباشر في المتصفحات التي توفر beforeinstallprompt، وإرشادات واضحة على iPhone/iPad بدل زر لا يستجيب.
- تحديث PWA cache إلى v17.

جميع مزايا Word/Excel/PDF/الشواهد/التقرير القابل للتعبئة ومركز البرامج محفوظة.
