مساعد الموجه الطلابي — الإصدار ١٢

أبرز تطويرات هذا الإصدار:
- كل أسبوع يفتح في مساحة مستقلة من قائمة منسدلة، بدل عرض الأسابيع السبعة متجاورة.
- تخطيط يومي واضح للأحد إلى الخميس مع التاريخ الهجري لكل يوم.
- حقول يومية: البرنامج/النشاط، الهدف، خطة التنفيذ، الملاحظات، وحالة التنفيذ.
- حفظ الخطة اليومية محليًا وإدراجها في JSON والتقارير.
- Excel احترافي: ورقة مستقلة لكل أسبوع، RTL، كليشة جديدة، مساحة شعار مستقلة، وخطة يومية.
- تعديل إعداد الطباعة في Excel إلى ملاءمة العرض A4 مع ارتفاع تلقائي للحفاظ على وضوح النص.
- خط Tajawal محلي من الحزمة المنقحة (ترخيص OFL مرفق) للعمل دون إنترنت.
- لا توجد اتصالات خارجية للتطبيق سوى رابط نظام نور الذي يفتحه المستخدم يدويًا.

ملفات النشر: ارفع جميع الملفات والمجلد assets كما هي إلى GitHub Pages.


الإصدار ١٢: Word حقيقي احترافي بصفحة مستقلة لكل أسبوع، مؤشر جاهزية التوثيق، زر Word أسبوعي، ونسخ خطة اليوم السابق.
