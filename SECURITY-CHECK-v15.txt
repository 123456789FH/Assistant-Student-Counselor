فحص أمان ساكن — مساعد الموجّه الطلابي — الإصدار ١٥
==================================================

نطاق الفحص: ملفات الحزمة النهائية المخصصة لـ GitHub Pages، دون تشغيل ملفات تنفيذية خارجية.

- لا يوجد مجلد node_modules داخل الحزمة.
- لا توجد ملفات .exe أو .dll أو .node أو .cmd أو .ps1 أو .bat أو .msi.
- التطبيق يعمل كملفات ويب ثابتة على GitHub Pages.
- سياسة Content Security Policy تمنع الاتصالات البرمجية الخارجية عبر connect-src 'none'.
- object-src وframe-src معطلان.
- الصور المرفوعة تُعالج محليًا في المتصفح، ولا توجد دالة لإرسالها إلى خادم خارجي.
- التخزين الأساسي محلي عبر localStorage.
- Service Worker يتعامل فقط مع ملفات نفس الأصل ويقيد الكاش بقائمة ملفات التطبيق.
- رابط نظام نور الموجود في الواجهة رابط خارجي مرئي يفتح عند اختيار المستخدم، ولا يمثل إرسالًا خلفيًا للبيانات.
- روابط Open XML الظاهرة داخل app.js هي namespaces معيارية لبناء DOCX/XLSX وليست طلبات شبكة.

ملاحظة: الفحص الساكن يقلل المخاطر الظاهرة في الكود والحزمة، لكنه لا يمثل ضمانًا مطلقًا ضد كل فئة ممكنة من المخاطر المستقبلية أو مخاطر منصة الاستضافة نفسها.
