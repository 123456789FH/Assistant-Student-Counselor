فحص أمان ساكن — الإصدار ١٧

- لا توجد ملفات exe / dll / node / cmd / ps1.
- لا يوجد eval أو new Function أو WebSocket أو XMLHttpRequest أو sendBeacon داخل app.js.
- سياسة CSP تمنع الاتصالات الخارجية (connect-src 'none').
- الرابط الخارجي الظاهر الوحيد للمستخدم هو نظام نور الرسمي، ويفتح بتفاعل المستخدم.
- صور الشواهد تظل مؤقتة في الجلسة وفق تصميم التطبيق، ولا تدخل في JSON.
- التنبيهات الجديدة داخلية ومحلية، ولا ترسل بيانات إلى خادم.
- إصلاح التثبيت لا يضيف مكتبات خارجية أو اتصالات جديدة.
