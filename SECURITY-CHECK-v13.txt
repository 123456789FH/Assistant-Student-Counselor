فحص الحزمة — الإصدار ١٣

- لا يوجد node_modules داخل حزمة النشر.
- لا توجد ملفات EXE/DLL/NODE/CMD/PS1.
- CSP يمنع الاتصالات الخلفية: connect-src 'none'.
- لا توجد WebSocket أو أوامر نظام أو PowerShell أو تنزيلات تنفيذية.
- رابط نظام نور رابط خارجي صريح يفتح فقط عند ضغط المستخدم.
- صور الشواهد: PNG/JPEG/WebP فقط، حد ٥ م.ب، إعادة ترميز JPEG وإزالة البيانات الوصفية الأصلية.
- حد الشواهد: ١٢ صورة لكل أسبوع لتقليل استهلاك الذاكرة على الجوال والآيباد.
- الصور مؤقتة ولا تدخل JSON أو التخزين المحلي.
- بيانات نموذج الشواهد النصية تمر عبر safeString وتُعقم عند العرض/التصدير.
- نموذج الشواهد لا يولد أوصافًا تلقائية للصور؛ الافتراضي «شاهد تنفيذ».
- تم اختبار JavaScript عبر node --check دون أخطاء.
- تم اختبار واجهة الإصدار ١٣ في Chromium: أسبوع واحد، ٥ بطاقات أيام، وحدة الشواهد، ومعاينة A4 دون أخطاء JavaScript.
- تم اختبار ٥ صور: صفحتان في المعاينة.
- تم اختبار Word حقيقي: ٤ صور = صفحة واحدة، ٥ صور = صفحتان، مع فتح/رندر ناجح.
- تم اختبار Excel الحقيقي بعد التعديل وملف ZIP الداخلي سليم.
- تم اختبار PNG: 2480×3508 بكسل.
